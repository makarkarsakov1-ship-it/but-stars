# ⚡ NEOBANK X — Банк Будущего

Интерактивный концепт футуристического онлайн-банка, выполненный в трендовом стиле **Glassmorphism** (эффект матового стекла) с неоновыми акцентами и элементами киберпанка. Проект представляет собой полностью рабочее Single Page Application (SPA) на чистом JavaScript без использования сторонних тяжелых фреймворков.

---

## ✨ Ключевые фишки и функционал

### 🔹 Базовые банковские операции
* **Управление балансом:** Динамическое обновление счета, анимация изменения баланса и функция скрытия конфиденциальных данных ("глазок").
* **Пополнение:** Интерактивное модальное окно с выбором метода (СБП, карты, Цифровой Рубль).
* **Мгновенные переводы:** Валидация полей, автоматический перерасчет баланса и логирование транзакций «на лету».
* **История активностей:** Динамический список последних операций с цветовой кодировкой (расходы/доходы) и иконками категорий.

### 🚀 Уникальные фичи (Next-Gen UX)
* **3D Tilt-эффект для карт:** Пластиковые карты реагируют на движение курсора мыши, создавая реалистичный объемный эффект наклона в 3D-пространстве.
* **Генератор виртуальных карт:** Возможность мгновенно выпустить одноразовую цифровую смарт-карту со случайным номером в один клик.
* **Умный сейф (Копилка):** Интерактивная шкала прогресса накопления на цель *"На перелет на Марс"* с возможностью быстрой отправки средств.
* **Крипто-Интеграция:** Встроенный мини-виджет кошелька с актуальными балансами в BTC и ETH.
* **Нейро-аналитика:** Круговая интерактивная SVG-диаграмма расходов по категориям.
* **Кастомизация:** Кнопка быстрой смены темы оформления (переключение на неоновый киберпанк).

## 🛠 Технологический стек

* **Markup:** HTML5 (Семантическая структура)
* **Styles:** CSS3 (Flexbox, Grid, CSS-переменные, `@keyframes` анимации, Backdrop-filter)
* **Scripts:** Vanilla JavaScript (ES6+, DOM Manipulation, 3D Математика для карт)
* **Icons:** FontAwesome v6.4.0 (via CDN)

---

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий или просто скачайте файлы проекта.
2. Убедитесь, что все файлы (`index.html`, `README.md`, `.gitignore`) находятся в одной папке.
3. Дважды кликните по файлу `index.html`, чтобы открыть банк в любом современном браузере.

## 🌐 Развертывание на GitHub Pages

Этот проект оптимизирован для бесплатного хостинга **GitHub Pages**:
1. Перейдите в настройки вашего репозитория (**Settings -> Pages**).
2. В разделе **Branch** выберите ветку `main` (или `master`) и нажмите **Save**.
3. Проект будет доступен по ссылке: `https://<ваш-логин>.github.io/<имя-репозитория>/`
